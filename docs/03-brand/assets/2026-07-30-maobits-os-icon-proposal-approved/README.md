- `maobits-os-icon-proposal-approved-original.png`: original approved image.
- `maobits-os-icon-proposal-approved-1024.png`: normalized 1024x1024 review asset.
- `maobits-os-icon-proposal-approved-512.png`: normalized 512x512 review asset.
- `maobits-os-icon-proposal-approved-256.png`: normalized 256x256 review asset.
- `maobits-os-icon-proposal-approved-128.png`: normalized 128x128 review asset.

Important:

These files are proposal assets only. They must not replace Android active launcher resources until the technical conversion and validation phase.
